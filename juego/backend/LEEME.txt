CONFIGURAR EL GUARDADO DE PUNTAJES

1. Abrí XAMPP e iniciá Apache y MySQL.
2. En phpMyAdmin, importá backend/crear_base.sql.
3. Copiá backend/guardar_puntaje.php a:
   C:\xampp\htdocs\juego35\guardar_puntaje.php
4. La URL que usa el juego es:
   http://localhost/juego35/guardar_puntaje.php
5. Si MySQL tiene otra contraseña o usuario, editá las variables $user y $password
   al principio de guardar_puntaje.php.
6. Ejecutá el juego, terminá la partida, escribí un nombre y pulsá "Guardar puntaje".

La tabla guarda nombre, tiempo en segundos y fecha. La conexión a la base de datos se
realiza desde PHP; Godot no se conecta directamente a MySQL.

Si el juego no puede conectar, comprobá que Apache y MySQL estén iniciados y que el PHP
esté exactamente en la ruta indicada.

SI XAMPP ESTA APAGADO
El puntaje no se pierde: el juego lo guarda en la PC y lo manda a la base solo, la proxima
vez que el servidor este prendido (al abrir una partida o al guardar otro puntaje).
Los archivos quedan en la carpeta de datos del juego (user://):
  - puntajes_pendientes.json  (cola que todavia no llego a la base)
  - puntajes_locales.csv      (copia para abrir con Excel)
En Godot: menu Proyecto > Abrir carpeta de datos de usuario.
Despues de actualizar el juego, volve a copiar guardar_puntaje.php a htdocs/juego35/
(para que respete la fecha original de los puntajes guardados sin conexion).
