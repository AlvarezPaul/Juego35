    Guía - Godot Engine

    (fundamentos empleados en la creación del proyecto)

    WASD y Click derecho para moverme dentro del proyecto de Godot.

    Obviendo que necesito una Camera3D para visualizar, preferentemente
    incluída en el personaje y en primera persona para el juego que
    estamos haciendo.

    Añadir WorldEnvironment y DirectionalLight3D si quiero poner gráficos
    básicos al mundo, el último es el sol, podemos ajustar ambos para
    generar un ambiente de oscuridad como es nuestro caso.

    Crear carpetas para organizar materiales, escenas, sonidos, etc.

    StandardMaterial3D para darle propiedades de material a nuestros
    objetos. El albedo es una de las características para cambiar el color.

    UI Interfaz del Usuario. Importante para el menú, mostrar textos o una
    barra de progreso.

    Recursos fundamentales de UI:

    Panel: un panel para poner generalmente de fondo, se puede usar para
    un menú por ejemplo.

    TextureRect: para poner una textura o imagen en un UI.

    Label: para poner texto fijo no editable en la UI.

    Button: botón al que se le puede añadir un texto y el usuario pueda
    interactuar con él y hacer algo.

    ColorRect: parecido a Panel, muestra un rectángulo ajustable con un color.

    Al apretar un “Button” que reproduzca un sonido:

    - Debo crear el botón dentro de la Escena Interfaz del Usuario primero
    que todo y decorarlo a mí manera.

    - Luego debo añadirle un nodo hijo llamado AudioStreamPlayer

    - Después crear un script en Button y arrastrar el AudioStreamPlayer al
    script para que se coloque y aparezca como @onready.

    - Añadir la función _on_pressed() -> void en el script abajo y agregarle
    a la misma la línea ‘audio_stream_player.playing = true’.

    Cómo hacer mi juego con temática oscura para
    juegos de terror

    Tener un WorldEnvironment para configurarlo, por defecto aparece de día

    Clickear el Environment, luego Sky, luego SkyMaterial y abrir las
    opciones Sky y Ground

    Cambiar el Top Color, Horizon Color, Bottom Color y Horizon Color a negro

    Podemos cambiar el ToneMap dentro de WorldEnvironment para que se vea
    algo brillante, o aún más oscuro para darle un buen efecto, Filmic viene
    por defecto, ReinHard para que se vea un poco más brillante, pero el
    recomendado para este estilo de juego es ACES.

    En Adjustments dentro de WorldEnvironment si lo habilitamos podemos
    ajustar el brillo, contraste y saturación, aunque esto podemos dejar
    que lo haga el usuario porque se puede ver distinto para cada monitor.

    Podemos habilitar SDFGI sin cambiar nada para agregarle más realismo,
    otra opción que está en WorldEnvironment.

    La opción Volumetric Fog sirve para agregar niebla, podemos configurar
    su color, densidad, emisión, energía de emisión y longitud de la niebla.

    Cómo agregar un menú de pausa

    Antes de hacer todo, debemos ir a Proyecto y Configuración de Proyecto,
    luego a Mapa de Entrada y crear una acción con el nombre Pausa y
    agregarle la tecla Esc (Escape)

    En “+” creamos la escena del menú de pausa como Interfaz del Usuario.

    La guardamos en Escenas o en alguna carpeta relacionada.

    Decoramos el menú a nuestro gusto, con un PanelContainer, botones
    y ajustamos para que se vea bien estéticamente.

    Como bloquear el mouse y que no se vea:

    Agregar en el script de la sala 3D, dentro de la función _ready el
    siguiente comando: “Input.set_mouse_mode(Input.MOUSE_MODE_CAPTURED)

    Si en el futuro queremos agregar un menú de pausa debemos hacer que
    al activar el menú de pausa el mouse sea visible.
